### 🛠 About the Project
This is a software licensing system designed to protect digital products. I designed the entire logic and workflow from scratch:
*   **Key Generation:** Creating unique license keys for various products.
*   **HWID Binding:** The system automatically binds a key to the user's hardware ID upon the first activation.
*   **Security:** Continuous validation of the key and HWID to ensure the software isn't shared or leaked.

This system has already been tested in the real world—I’ve used it to automate processes and manage sales within private communities.

### 💻 Tech Stack
*   **Backend:** Python + FastAPI.
*   **Database:** PostgreSQL (SQLAlchemy).
*   **Environment:** Docker (I'm currently learning to containerize my services for easier deployment).
